## ✨ About the Project

**Oddly Specific Museum** is a playful digital museum dedicated to documenting the oddly specific, universally relatable and wonderfully absurd experiences of everyday human life.

From the 47 browser tabs we swear we'll read later to the chair that mysteriously becomes a wardrobe, the museum celebrates the little things that make being human so entertaining.

It reimagines the traditional museum experience as an interactive digital archive, where visitors can explore unusual exhibits, discover unexpected connections and contribute their own oddly specific observations.

Because some things deserve to be remembered. Even if nobody asked.

## 🎨 Design Philosophy

The visual identity draws inspiration from experimental editorial design, contemporary digital art galleries and internet culture.

The design features:

- A bold purple, mint, periwinkle and pink colour palette.
- Oversized typography and expressive layouts.
- Playful exhibit cards with layered shadows and rotations.
- A scrolling archive ticker.
- Contrasting colours and distinctive visual elements.
- A responsive, playful browsing experience.

The goal was to create an interface that feels like an actual experience rather than another conventional website.

## 🚀 Features

- **Interactive Homepage:** An expressive landing page introducing the museum and its featured collections.
- **Exhibit Gallery:** Browse a collection of oddly specific everyday experiences.
- **Exhibit Details:** Explore individual exhibits and their descriptions.
- **Search and Filtering:** Discover exhibits based on keywords and categories.
- **Surprise Me:** Discover a random exhibit.
- **Exhibit Submissions:** Contribute your own oddly specific experiences.
- **Responsive Design:** An interface designed to adapt to different screen sizes.

## 📂 Getting Started

Want to explore the project locally?

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/aayushisomkuwar/oddly-specific-museum.git
```

**2. Navigate into the project**

```bash
cd oddly-specific-museum
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
